# PortDeck 🎮

Launcher independente de ports para Windows, com experiência de biblioteca em tela cheia inspirada no Steam Big Picture.

## Estado do projeto
- **v0.1.2:** executável nativo Win32, comprovadamente abriu e iniciou jogos no PC do usuário.
- **v0.2:** nova interface em desenvolvimento; biblioteca em tela cheia, capas, animações, controles e migração do banco antigo.

## Desenvolvimento
A interface 0.2 está sendo desenvolvida na branch `feature/big-picture-ui-v0.2`, sem modificar a versão estável.

## Roadmap
1. v0.2: interface e navegação por controle.
2. v0.3: capas automáticas por nome, com confirmação do usuário e API licenciada.
3. v0.4: perfis e identificação de controles Xbox / PlayStation / 8BitDo.
4. v0.5: favoritos, busca e filtros.
5. v0.6: integração e retorno ao Steam Big Picture.

O PortDeck apenas executa jogos que o usuário já possui; não distribui jogos ou firmware.
